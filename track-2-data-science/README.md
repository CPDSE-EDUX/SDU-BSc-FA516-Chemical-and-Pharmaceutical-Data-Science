# Track 2: Data Science Foundations

What happens to chemical data in the FA516 course before any model sees it: where the data
comes from, what shape it arrives in, everything that is wrong with it, and how to look at
it. This is the part of the work that decides whether the modelling later is worth anything.

Assumes track 1.

## Topics

- **Chemical data types & formats**: the common data types, chemical file formats, getting data from PubChem and ChEMBL
- **Data preprocessing & cleaning**: cleaning a molecule list, missing values, scaling, bioactivity units, outliers
- **EDA & visualization**: exploring a dataset step by step, property distributions, comparing groups, comparing many properties at once
