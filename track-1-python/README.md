# Track 1: Python Fundamentals

The starting point of the FA516 course. You learn enough Python to be dangerous with chemical
data: variables and types, control flow, functions, the four container types, and then
the libraries the rest of the course rests on: RDKit for molecules, and NumPy, SciPy and
pandas for numbers and tables.

No prior Python is assumed.

## Topics

- **Python basics**: variables, types and operators; if/else and loops; functions
- **Lists & data structures**: lists, tuples, sets, dictionaries, comprehensions
- **Cheminformatics with Python**: installing RDKit, molecules from SMILES, drawing them
- **NumPy, SciPy and pandas**: arrays, DataFrames, statistics and curve fitting
